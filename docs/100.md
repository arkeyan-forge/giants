# Giants: what "100 %" means, and what is left

> **Purpose:** the bar Giants must reach, what is done and what is left, by area · **Status:** current (2026-10-27) · **Tags:** [Giants]

Legend (every game): ✅ done, 🔧 in progress, ⏸ paused, ❌ not done. Owners: the user, the tester, the designer, the developers.

## Definition
The same bar as SSA ([../../ssa/docs/100.md](https://github.com/arkeyan-forge/spyros-adventure/blob/main/docs/100.md)), for Giants: installed from the player's disc
through Skylauncher on macOS, Windows and Linux; every mode plays from start to end with real and emulated portals and
all figures; as smooth as the console or better; no save or figure ever lost; every part documented.

  itself; the `Skylanders/Giants` data folder ([history.md](history.md), "Installing Giants").
- ✅ **Toy Box, variants and upgrades from the disc (2026-10-26):** the redesign (shelf, versions with artworks, upgrades by name),

  (Windows under Wine, Linux in Docker: the first level reached, no crash; an x86 start-up crash in the generated code fixed);

- ✅ **Sidekicks and the accepts list (2026-10-27):** all 8 pet items ran in play; Giants has no toy-type check in code, its toy
  definitions are the check and the catalogue matches them (`tools/toy_tables.py`); pets share the item seat
  ([figures.md](https://github.com/arkeyan-forge/forge/blob/main/docs/runtime/host/figures.md)).
- ✅ **The game's own app icon on macOS (2026-10-27):** made from the disc at install ([game_art.md](https://github.com/arkeyan-forge/forge/blob/main/docs/runtime/host/game_art.md), "The app icon").
- ✅ **A 1-hour soak (2026-10-27):** from the title through the tutorial into Chapter 1, isolated, `nice`, the walking and
  attacking presses of `tools/regress/giants_press.py` to 3700 s: **no crash, no fault or `[guard]` line, 29.7-30.0 fps in every
  10-minute window**, resident memory about 850 MB in the first 12 minutes, 825 MB at 21 min, then a step down to 290 MB by 31 min (as in SSA's soak:
  most likely the system compressing pages; nothing grows).
- ✅ **No vertex texture fetch in Giants' 264 vertex shaders** (SSA's grass fix does not touch the cache), and all 4394
  shaders of `global.bld` translate (checked 2026-10-27 with the current XenosRecomp). One run-time pixel shader, `95CAD664E1351A05`
  (not on the disc list; built at run time, drawn once in the first minute, primitive 6) fetched a **1D texture**
  (`tfetch1D`): since 2026-10-27 the translator emits it as a one-row 2D fetch and the runtime binds the texture, so it
  translates and draws (first at frame 921, the tutorial's first scene). See [shaders.md](shaders.md).
